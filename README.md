Sunset Cover Maker turns your own photos and a caption into multi-panel cover art in the style of a Vice City poster: load photos from your machine, paint them into panels (one photo across several panels, or a different photo per panel), drag and zoom each photo inside its panel, pick a layout (hero-and-three, four-panel grid, full bleed, nine-panel mosaic, tilted snapshots), pick a sunset or neon colour grade, write a bold caption with a script line, and export a PNG in 1080×1080, 1080×1350 or 1920×1080. Everything runs offline in the browser — photos are never uploaded.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
